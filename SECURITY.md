# Seguridad de OrigenLM

Gracias por ayudar a mantener seguro el proyecto.

## Reportar vulnerabilidades

**No abras un issue público ni publiques pruebas de explotación o credenciales.**

Si GitHub permite el reporte privado de vulnerabilidades para este repositorio,
utiliza la opción **Report a vulnerability** en la pestaña Security. De lo contrario,
contacta al mantenedor mediante un canal privado para acordar una vía de comunicación segura.

Incluye el módulo afectado, el impacto y pasos mínimos para reproducir el problema,
sin compartir tokens, contraseñas ni datos de otras personas.

## Alcance

El repositorio contiene código de investigación y herramientas experimentales.
No se garantiza que el sistema sea apto para producción o ejecución de código no confiable.
Las herramientas que acceden a red, sistema de archivos o terminal requieren permisos
explícitos y aislamiento adecuado.

No publiques datasets privados ni checkpoints en los que se hayan incorporado secretos.

Los cambios de seguridad se revisan y se prueban antes de su divulgación.
